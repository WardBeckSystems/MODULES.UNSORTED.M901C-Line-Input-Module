| **Weight** | 750 grams. The M901C provides the line level stereophonic input channel facility for the Renaissance series of radio consoles. The input source selector allows two separate stereo inputs to be connected to the input module. Each input has its own preamplifier, allowing individual gain trimming and common mode balancing of the discrete source inputs. The sensitivity controls are front panel accessible. These continuously variable controls provide adjustment for input source levels from -10 to +10 dBu. A mode selector is provided which gives the operator the ability to reconfigure the stereo source material in the following manner. 1) Provide normal stereo. 2) Feed the left input channel only to both the left and right outputs. 3) Feed the right input channel only to both the left and right outputs. 4) Combine the left and right outputs into a left plus right mono output. The preamplifier outputs, once selected, appear at the module connector for the insertion of optional processing. The cue buss feed is connected to the insert return line so that pre-fade listening of source material can take place before any input module level control. Direct left and right channel outputs are provided at the module connector. These direct feeds maybe optionally used for multitrack applications or to feed the console mix-minus system. The output from this module maybe assigned to any or all of four stereo program busses. These buss selectors are preceded by a centre detent balance control, giving the operator the ability to trim level imbalances between the left and right channel signals. Two auxiliaries are also integral to the module, a monophonic and a stereo one. Both are assignable individually pre or post VCA, and each auxiliary has it's own level control and on/off control. The module also contains a &quot;blind assignable&quot; monophonic post VCA buss output. This buss maybe utilized for use by the console mix minus system. Unitary control of most module functions is also available at the module connector for machine control as well as external control inputs. Outgoing control signals are furnished as open collector paths to control common when activated. Comprehensive internal module logic allows intelligent control of external machines, with all outgoing control signals following module source selection (source A or B). A momentary closure to control common (through an open collector transistor), is provided when the module is turned on or off for both theA orB source. This totals four independent outputs, one start and stop signal for both theA and B module sources. An additional sustained closure to common is provided for both theA and B input sources. This closure is active when the main channel is on, and is provided for external use. These outputs are also internally assignable to one or all of three internal console muting busses. These busses run to the M905 monitor modules in the console system for muting the monitor speakers. The internal buss structure of the console includes a cue control buss. If a module is assigned to this buss, putting the module into cue will activate the auto cue function in the M905A control room monitor module. The lamp internal to the channel off button is uncommitted and is brought out on the module connector. This is intended for utilization as a tally indicator for external machinery. Module control inputs are also configured to activate when a closure to control common is provided. The module can be turned on and off, the cue can be toggled, and the source can be selected between A and B by simply grounding the appropriate module connector pin. Program buss assignment is also possible external to the module. Again, a closure to control common will effect this assignment. to change a previous buss assignment, the electronic latches require clearing before loading them with new buss assignments. A closure to common will also perform this function. External control of the VCA within each module is also brought out to the edge connector. Application of a voltage between 0 and 5 volts DC will bring the attenuator from no external attenuation to full attenuation from the current fader position. This feature can be of benefit for automated cross-fading. The M901C Stereo Line Input module is packaged ina 1.5&quot; wide x 16.2&quot; high x 6.6&quot; deep space. This module derives its power from the console system bipolar +/-24 volt power supplies. 1) Source &quot;B&quot; Select Depressing this momentary switch (SW2), enables the &quot;B&quot; input source and disables the &quot;A&quot; input source selection (if it was selected). Double pressing the active switch will cancel the selection. 2) Source &quot;A&quot; Select Depressing this momentary switch (SW1), enables the &quot;A&quot; input source and disables the &quot;B&quot; input source selection (if it was selected). Double pressing the active switch will cancel the selection. This source is selected automatically when power is supplied to the module. 3) &quot;L&quot; Mode switch Switch SW10, an alternate action pushbutton that works in conjunction with the &quot;R&quot; mode switch, SW11, to enable stereo mode selection. Please refer to section 17 fora full description of the operation of these switches. 4) P3 Select Switch SW14, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 3 stereo buss in the console. 5) P1 Select This electronically latched, momentary switch, (SW12), assigns the stereo audio signal to the program 1 stereo mix buss. This assignment is performed automatically on module power-up. 6) Balance Control This centre detent rotary control determines the level balance between the left and right stereo outputs which feed the console program buss assignment switches. 7) AUX 1 prefade or post fade selection Switch SW6 determines the source for the AUX 1 console output, either pre-VCA or post-VCA. The switch is illuminated when depressed, indicating post-VCA selection. 8) AUX 1 level control This level control (R66), allows the adjustment of the level of the audio signal fed to the mono auxiliary buss. 9) AUX 1 on/off This alternate action switch (SW7), assigns the auxiliary signal to the console mono auxiliary mixing buss. 10) Q This momentary electronic switch assigns the pre-fader signal to the console's stereo cue buss. This provides a pre-fade listen feed for cueing. 11) OFF This switch turns off the audio feeds from the console mixing busses, and contains an externally accessible lamp for machine tally purposes. 12) ON This momentary switch enables the audio feeds to the console mixing busses. 13) &quot;B&quot; source right channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the right channel of the &quot;B&quot; source. 14) &quot;B&quot; source left channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the left channel of the &quot;B&quot; source. 15) &quot;A&quot; source right channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the right channel of the &quot;A&quot; source. 16) &quot;A&quot; source left channel sensitivity control This front panel accessible screwdriver trim control allows adjustment of the input sensitivity of the left channel of the &quot;A&quot; source. 17) &quot;R&quot; mode switch Switch SW11, along with left mode switch SW10, control an active solid state mode switch. With the left and right switches in the up position and the indicators off, the module acts as a normal stereo module. Depressing the right switch presents the right channel audio to both the left and the right channel outputs. Depressing the left switch alone feeds the left channel audio to both the left and right channel outputs. Depressing both the left and right mode switches together sums the left and right signal and couples the mono result to both the left and right channel outputs. 18) P4 buss assignment switch Switch SW15, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 4 stereo buss in the console. 19) P2 buss assignment switch Switch SW14, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 2 stereo buss in the console. 20) AUX 2 prefade or post fade selection Switch SW8, determines the source for the AUX 2 console output, either pre-VCA or post-VCA. The switch is illuminated when depressed, indicating post-VCA selection. 21) AUX 2 level control This level control (R77), allows the adjustment of the level of the audio signal fed to the stereo auxiliary buss. 22) AUX 2 on/off This alternate action switch (SW9), assigns the auxiliary signal to the console stereo auxiliary mixing buss. 23) Main channel fader This 105mm Penny and Giles linear fader controls the main channel voltage controlled amplifiers. Inputs The M901C Stereo Line Input Module is capable of selecting between two stereo sources. The SA14-281 Input Amplifier Assembly provides the preamplification and source selection; as well as mode switching for the module. Please refer to the subassembly section of the manual fora detailed circuit description of this assembly. Control of the SA14-281 is provided on the M901C main circuit board. Please refer to drawing B 901-02-010/2 for this description. On power up, a reset circuit consisting of R107, C79, C113, and CR27 provides a momentary logic 0 (0 volts DC) to globally reset the logic circuitry on the module. This signal provides the reset signal to U14 through CR13 and CR14. U14 is a dual flip-flop that controls the source selection (source A or B). On power up theA source is enabled and the B source is disabled. Selection of the B source is enabled by closing SW2 to control common. Switch bounce is eradicated by U13 sections E and F, a Schmidt trigger inverter. This clean switching signal is coupled to the toggle input of U14, and via CR3, to the direct reset of the flip-flop for source A. This connection provides electronic alternate action operation for the source selection. By double switching the currently active switch, it too is disabled. This allows disabling of both input sources, a function not normally available with a mechanically interlocked switch. External A and B source selection is available at edge card connector P2 pins 26 and 25 respectively. Selecting source A directly sets the flip flop forA on and resets the B flip flop to the off state. Likewise, selecting source B directly resets theA input off. Source selection is tallied via illumination in the associated pushbutton. The lamp circuitry is reproduced on drawing number B 901-02-010/3. Examining the B source tally lamp, a logic 0 at tag &quot;B&quot; on R141 turns Q13 on. This transistor provides current to the base of transistor Q14, effectively shorting out DS3, preventing it from being illuminated. A logic 1 at R141 disables Q13, as well as Q14. This allows DS3 to illuminate. The lamps are all run in series via a constant current source comprised of Q39, and R192 through R194. This provides approximately 20 mA of current through the series LED string. The illumination was handled in this fashion to maintain constant current consumption no matter the number of lamps on ina string. Inserts Two unbalanced inserts are provided, one for each channel; following the input selector. Attenuator The linear attenuator, ATT1 (on drawing B901-02-010/3), controls two voltage controlled amplifiers (VCA), U1 and U2 and associated components (on audio schematic sheet B 901-02-010/1). |
| **Detailing U1's circuitry** | The unbalanced insert return is AC coupled to U1 via C1 and R1. VCA U1 is configured as a non-inverting voltage controlled amplifier. The gain of the amplifier is controlled by the voltage present at pin 11, which is bypassed to control common by C4 to damp any external sources of interference with this control signal. Trim control R2 is used to trim the gain cell symmetry in the VCA so that signal distortion is minimized. Trim control R6 is adjusted to null any feedthrough at the VCA output should the VCA control port be modulated. Resistors R10 through R13, CR1 and CR2, and Q1 and Q2 are configured as a simple bipolar emitter follower that boosts the current output capability of U1. The VCA control amplifier on sheet B 901-02-001/3 consisting of U25, U26 and associated components generates a piece-wise linear correction for the attenuation characteristic of U1 and U2. This amplifier generates an overall pseudo-audio taper characteristic for the attenuator circuit. Balance Control A centre detent balance control, R36, provides stereo balance adjustment for the audio feeds going to the program buss assignment switches. Buss Assignment Solid state active buss assignments are performed by U5 through U8. These switches are controlled by the control logic in the module, and are active when the channel is switched on, the fader is brought up from the infinity position, and the program has been assigned. The Program 1 buss can be assigned by moving programming jumpers LK1 and LK2. In the &quot;1&quot; position, the Program 1 feed is assigned to the program 1 music buss. In the &quot;3&quot; position, the Program 1 feed is assigned to the voice buss. The blind mix minus buss is assigned to the module output when LK3 is placed in the &quot;1&quot; position, and is active when the channel is turned on. Auxiliary switching |
| **The monophonic and stereo auxiliaries** | AUX 1 and AUX 2, are selectable pre or post VCA. The pre and post VCA stereo audio is summed with active summing amplifiers consisting of U3 and U4 respectively. These summed feeds are coupled to U9, a four channel solid state multiplexer chip. This determines whether the pre or post VCA signal is selected to the AUX 1 level control, R66. The level output from R66 is coupled to the buss assignment switch, U12 pin 4. |
| **The stereo auxiliary** | AUX 2, functions ina similar fashion, the exception being that left and right signals remain discrete. The pre and post VCA selection is performed by U10. The AUX 2 level control is R77. Buss assignment is controlled by U12 at pin 14 and 15. U12 is active when the Auxiliary is turned on from its associated switch. Channel Control Logic Channel On Momentary operation of the channel on switch SW4, will produce a negative going pulse at U15 pin 13, resulting indirectly setting one of the flip flops in U17. Alternatively, a momentary closure of P2 pin 44 to ground will have the same effect. Once the flip flop is preset, its output at pin 15 changes from logic 0 to logic 1. This enables the VCA control amplifier, the Channel On lamp, and the program assignment buss controls (U21 and U23 sections C and D, and CR45 through CR50 and CR57 through 62). An open collector transistor, Q11 or Q12 is latched on, again depending on source selection, when the channel is on. These outputs can be used for external muting and signalling functions and are capable of sinking 20 mA to control common. A logical OR is realized with CR31 through CR33, and CR35 through CR37. These OR gate inputs are assignable to the internal muting busses in the console through a series of user-programmable links; LK7 through LK12. Notice that source A can mute a different buss configuration than source B. Turning the channel on also causes a momentary low impedance path to ground to be enabled via an open collector transistor. This is intended for machine control applications, and is logically steered to follow the input source selection. Transistor Q5 through Q8 handle this task, and are capable of sinking 20 mA to control common. Channel Off Momentary operation of the Channel Off switch SW3, or momentary ground closure of the External Off control input at connector P2 pin 44 will result ina negative going pulse at U15 pin 13. This results ina direct reset of the &quot;A&quot; section of flip-flop U17. This produces a logic 0 at pin 15 of U17. Consequently, the VCA amplifier is disabled, the Buss switches are disabled, and the Channel On lamp is extinguished. A momentary closure to control common via an open collector transistor which follows input source selection is available at module connector P2 pin 36 and P2 pin 35 for theA and B inputs respectively. The lamp integral to the Channel Off switch is uncommitted and available at module connector P2 pins 45 and 46. This can be used for external machine tally purposes (CD ready indicators, for example). In addition to the normal channel pushbutton off, operated by the Channel Off function detailed above, the channel output is also disabled whenever the channel attenuator is moved to the infinite position (∞). This disables the VCA control amplifier and the Program Buss switches. However, the tally lamps for Channel On, muting controls and Buss assignment switches remain unaffected. The B section of U17 is used to control the solid state cue switches. The flip-flop will change state each time a negative going transition occurs at pin 5 of U15. Consequently, with each input pulse, the Cue channel toggles on and off. This alternate action can be invoked by either momentarily closing Cue switch SW5 (Q), or momentarily grounding of the external Cue control input at module connector P2 pin 41. The status of the Cue channels is indicated by DS15, internal to SW5. An additional feature ensures that the Cue channels are always switched off whenever the attenuator is moved into or away from the infinity position; regardless of the prior state of the Cue channels. The control signal for this action is initiated by the change of state of the end of travel switch integral to the attenuator. The resulting level change, is processed through U15, U16D, and U18. The output produced at pin 4 of U10 will always be a negative going pulse of approximately 500 milliseconds duration. Diode CR28 passes this pulse to U17 pin 8, which directly clears the cue section of the flip-flop, disabling the Cue channels. All logic control inputs are buffered to guard against switch bounce and spurious noise. Power Supply Decoupling Please refer to drawing number B 901-02-010/3. An active decoupling network consisting of Q45 through Q48, U27 and associated components decouple the incoming +24 volt power supply voltage down to +/-18 volts, -22 volts, and +6 volts for use in the module. CR84 and CR85 prevent module damage in the event of power supply reversal. The decoupling network drops the +/-24 volt power supply inputs down to a nominal +/-18 volts for use by the audio circuitry. Additional decoupling to +6 volts is handled by U27, R236, and R237. Integrated circuit U27 is an adjustable three terminal regulator set for 6 volts of output voltage for utilization by the logic circuitry within the module. The -22 volt supply is utilized by the LED current source driver for the module indicators.
